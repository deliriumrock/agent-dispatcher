# agent-dispatcher

`disp` — диспетчер сессий AI-агентов: Claude Code, Codex CLI, Gemini CLI.
Одна таблица на все открытые сессии: какая работает, какая ждёт тебя, какая
закончила и ждёт, пока ты посмотришь результат.

- Агент сам зовёт тебя: уведомление на рабочий стол или в Telegram, когда он
  упёрся в разрешение или закончил длинный ход.
- Ничто не пропадает из списка без явного «убрать» (`disp ok`, в панели — `x`).
- Живая панель для zellij: где какая сессия, переход к ней, ответ агенту «да»,
  лента времени. Молчащую сессию проверяет по процессам: идёт долгая команда,
  агент завис или его уже нет.

## Установка

Нужны Linux или macOS и Rust 1.90 или новее. Переход к агенту и ответ «да»
работают через zellij. Проверка процессов молчащей сессии читает `/proc` и
есть только на Linux; на macOS такая сессия просто «молчит».

```sh
make install          # ~/.local/bin/disp
disp install claude   # хуки в настройки агента; так же codex и gemini
disp doctor           # какие агенты уже шлют события
```

Графическая оболочка — отдельный пакет, собирается несколько минут:

```sh
make install-gui      # ~/.local/bin/disp-gui
disp gui --window     # отдельным окном; без ключа — в панели терминала через term-everything
```

Значок в трее — на Linux и macOS:

```sh
make install-tray     # ~/.local/bin/disp-tray
disp watch            # панель в терминале и заодно значок в трее
disp tray             # только значок; работает в фоне, отдельно от терминала
disp tray --autostart # показывать при входе в систему (--no-autostart — перестать)
```

`disp watch` и `disp gui` сами показывают значок, если его ещё нет. Значок
один на всех и остаётся, когда панель закрыта. Не показывают при
`DISP_TRAY=0` в настройках, в сеансе SSH и без рабочего стола.

Значок, по старшинству: жёлтый кружок с числом — столько агентов ждут тебя;
голубое кольцо — сессии работают; зелёный кружок с числом — не работает
ничего, остались готовые; серое кольцо — нет ни работающих, ни готовых. Меню в
том же порядке, что таблица: «Ждут тебя», «Работают», «Простой», «Готово». У
каждой сессии кнопки «Ответить «да»», «Перейти к панели», «Убрать из списка»;
двойной щелчок по значку открывает панель. На Linux значок говорит с оболочкой по D-Bus
(StatusNotifierItem), GTK не нужен; в GNOME значки показывает расширение
AppIndicator. На macOS значок живёт в строке меню, без значка в Dock.

Настройки — переменные `DISP_*` в окружении или в файле `~/.config/disp/env`:
Telegram (`DISP_TG_TOKEN`, `DISP_TG_CHAT`), порог уведомления о конце хода
(`DISP_NOTIFY_MIN_SEC`, 120 с), порог молчания (`DISP_STALE_MIN`, 30 мин),
подписи панелей zellij (`DISP_PANE_LABEL=1`). Полный список — в спецификации.

## Каждый день

```sh
disp watch       # живая панель и значок в трее; ? — все клавиши
disp             # таблица незакрытых сессий
disp show <id>   # промпт, последний ответ, подзадачи
disp ok <id>     # результат посмотрел — убрать
disp yes <id>    # ответить ждущему агенту «да»
disp log         # что происходило, пока тебя не было
```

## Документы

- `dispatcher-v0.md` — спецификация: как устроено, статусы, установка,
  ограничения. В приложениях — первая версия на bash и приёмочные тесты.
- `ROADMAP.md` — что дальше: сервис `disp serve`, кнопки в Telegram, телефон.
- `disp` в корне — та самая первая версия на bash (0.1.0), для сравнения.

## Разработка

```sh
make test   # модульные тесты и приёмочный набор test.sh
make bump   # номер сборки +1 (0.8.005 → 0.8.006) перед сборкой, которая уходит в работу
```

Состояние лежит в `~/.local/state/disp/`. Для опытов задавай `DISP_STATE_DIR`
и `DISP_CONFIG` во временный каталог, иначе записи попадут в настоящий список,
и `DISP_TRAY=0`, иначе `disp watch` покажет в трее ещё один значок.
